# 🛒 E-Commerce Website

A simple full-stack E-Commerce web application developed using HTML, CSS, JavaScript, PHP, and MySQL.  
This project allows users to register, login, view products, and manage shopping features.

---

# 📌 Features

- User Registration
- User Login Authentication
- Product Display Page
- Shopping Cart
- Checkout Page
- Responsive User Interface
- Database Connectivity with MySQL
- Backend Functionality using PHP

---

# 🛠 Technologies Used

## Frontend
- HTML5
- CSS3
- JavaScript

## Backend
- PHP

## Database
- MySQL

## Server
- XAMPP

## Version Control
- Git & GitHub
